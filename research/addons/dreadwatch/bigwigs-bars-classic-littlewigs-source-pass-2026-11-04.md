## BigWigs Bars.lua: concrete producer → message → consumer → cleanup

`BigWigs_Plugins/Bars.lua` **2,125 lines**. `OnPluginEnable` 1455–1474 subscribes `BigWigs_StartBar`, `PauseBar`, `ResumeBar`, `StopBar`, `StopBars`, `OnBossDisable`, `OnBossWipe`, `OnPluginDisable`, configure/profile, plugin comm and DBM custom-bar bridge. `OnPluginDisable` 1477–1485 stops bars in both anchors. `getBar` 1438–1453 selects matching module+text, or **eventId** when supplied. `PauseBar` 1532–1544, `ResumeBar` 1546–1559, `StopSpecificBar` 1564–1576 search normal then emphasized anchor; `StopModuleBars` 1578–1594 stops all owned bars in both. `GetBarTimeLeft` 1606+ exposes remaining time. LibCandyBar stop callback `barStopped` 1257+ cleans anchor tracking and styling.

`CreateBar` 1798–1858 constructs a LibCandyBar, stores `bigwigs:module`, `option`, optional `eventId`, anchor, label, icon and indicator metadata. Initial-font workaround at 1848–1854 avoids comparing secret labels unless nonsecret, and can match by eventId. `BigWigs_StartBar` 1883–1922 **rejects secret text without eventId**, stops an existing matching bar, creates/starts new bar, sets `maxQueueDuration` pause-on-done, handles emphasis threshold and callback, rearranges anchor. `BigWigs_BarCreated` and `BigWigs_BarEmphasized` broadcasts here are explicitly **Retail-only** (1914–1921). Important distinction: **bar eventId is identity/secret-safe matching metadata, not the boss spell key**.

**Classic producer source:** `BigWigs_Core/BossPrototype_Classic.lua` `Bar` 4334–4379, `CDBar` 4388–4433, `TargetBar` 4441–4478 and `CastBar` 4486–4519 emit `BigWigs_StartBar`, `BigWigs_StartCountdown`, and timer-analysis messages (`BigWigs_Timer`, `TargetTimer`, `CastTimer`). `StopBar` 4525–4539 and `StopCastBar` 4544–4547 emit both StopBar and StopCountdown. `PauseBar` 4553–4556 emits PauseBar plus StopCountdown; `ResumeBar` 4562–4569 emits ResumeBar and may restart countdown. Source comments explicitly describe eventId argument as **Retail only** (4333, 4387, 4485); do not claim it works on Forever.

**Custom timer bridge:** `Bars.lua` `startCustomBar` 2023–2059 parses time/text, throttles repeated remote bars to 1.2s, requires group leader/assistant for remote, builds `bwcb` ID, cancels existing completion timer for same ID, sends StopBar for zero duration or schedules completion `BigWigs_Message` and emits StartBar/Timer. `DBM_AddonMessage` 2062–2065 and `BigWigs_PluginComm` 2068–2074 feed the bridge. **IN concern:** completion timer cancellation on ordinary boss-bar stop is not equivalent to custom-timer cancellation; audit `timers` table lifecycle separately. No native `LoggingCombat()` ownership is implied.

**Message consumer:** `BigWigs_Plugins/Messages.lua` **1,030 lines**, `OnPluginEnable` 794–810 subscribes `BigWigs_Message` and config/profile; `BigWigs_Message` 940–979 filters/prints normal/emphasized warnings; `ENCOUNTER_WARNING` 982–1019 is a separate Blizzard event consumer, gated by `allowBlizzMessages`. **UN:** whether that native event is registered/delivered on Forever; handler existence does not prove registration. `BossPrototype_Classic.lua` `Message` 3751–3765, `PersonalMessage` 3771+, stack/target/secret variants send `BigWigs_Message`. More consumers of StartBar/Timer/Message must be enumerated across other plugins before claiming *every* consumer covered.

## Classic branch versus modern/Forever

`BigWigs_Core/BossPrototype_Classic.lua` **5,136 lines** versus `BossPrototype.lua` **5,407**. Classic `Enable` 664–704 sets enabled, resets scheduled events, adds to enabledModules, registers `ENCOUNTER_END` when encounter ID exists, pet/range checks, invokes `OnBossEnable`, attempts mid-fight recovery and emits `BigWigs_OnBossEnable`. `Disable` 716–835 calls `OnBossDisable`, cancels all timers, clears scheduled state; if last module, unregisters `COMBAT_LOG_EVENT_UNFILTERED` **only when not isModern** (733–735), clears pet/nameplate/scanning caches; otherwise removes module scans, then unregisters unit events, clears event/widget maps, rebuilds allowed-event map, cancels say countdowns, resets engagement/stage state and emits `BigWigs_OnBossDisable` except wipe. `Reboot` 837–845 emits `BigWigs_OnBossWipe` then disables/re-enables. **SC:** Classic branch contains explicit `if not isModern` combat-log registration cleanup and Retail-only eventId comments; **IN:** the modern/Forever path may use different event and secret-data transport, requiring independent inspection. The `COMBAT_LOG_EVENT_UNFILTERED` listener is **not** native log recording.

## LittleWigs: concrete module paths, multiple families

**LittleWigs_Classic/Deadmines/MrSmite.lua** (98 lines): `NewBoss` line 5; `RegisterEnableMob(646)` line 7; `SetEncounterID(mod:Retail() and 2970 or 2745)` line 8, an explicit **game-type-dependent encounter ID**. `OnBossEnable` 25+ registers `SPELL_CAST_START` and `SPELL_CAST_SUCCESS` via `:Log`; `OnEngage` 37+ starts cooldown bar. `PistolShot` 61+ emits red warning and CDBar; `SmiteStomp` 71+ uses thresholds to warn phases; `SmiteSlam` 93+ emits warning and CDBar. No local `OnWipe`; shared BigWigs disable/cleanup applies **if module actually loads** (UN on Forever).

**LittleWigs_Classic/Stratholme/TimmyTheCruel.lua** (80 lines): `NewBoss` 5, enable mob 10808 line 7, encounter 474 line 8; `OnBossEnable` 24–32 subscribes spell success and conditionally `INSTANCE_ENCOUNTER_ENGAGE_UNIT`; `OnEngage` 38+; `RavenousClaw` 59+ warns/restarts CDBar; `Enrage` 65+ warns at 50% and accelerates claw bar; `Fixate` 74+ CDBar. **LittleWigs_BurningCrusade/TheMechanar/Pathaleon.lua** (87 lines): `NewBoss` 5, enable mob 19220 line 7; `OnBossEnable` 30–40 explicitly registers `ENCOUNTER_START` and `ENCOUNTER_END`, plus summon/aura combat-log callbacks; `OnEngage` 43–44 registers `UNIT_HEALTH`; `ENCOUNTER_START` 51+ matches ID; `ENCOUNTER_END` 57–63 routes status to `:Wipe()` or `:Win()`; `DominationRemoved` 85–86 stops target bar. **SC:** explicit native encounter event handling is a per-module pattern, not universal across LittleWigs.

**LittleWigs_BurningCrusade/HellfireRamparts/Vazruden.lua** (90 lines): `NewBoss` 5, three enable mobs line 7; encounter ID is **commented out** line 8 due to missing boss frames; `OnBossEnable` 31–35 registers RAID_BOSS_EMOTE and native encounter events; `OnEngage` 38–41 registers `PLAYER_REGEN_ENABLED` wipe check and `UNIT_HEALTH`; `RAID_BOSS_EMOTE` 48+ stage warning; `ENCOUNTER_END` 62–69 defers `:Wipe()` by 1 second to avoid re-registering ENCOUNTER_END during dispatch, otherwise wins. **SC:** demonstrates a concrete event-mutation/reentrancy workaround.

**LittleWigs_TheWarWithin/PrioryOfTheSacredFlame/CaptainDailcry.lua** (145 lines): `NewBoss` 5, encounter ID 2847 line 13; `OnBossEnable` 41–49 registers seven cast/periodic/aura log paths; `OnEngage` 52–61 seeds four cooldown bars; explicit `OnWipe` 63+ and `OnWin` 70+; `BattleCry` 81+ warns and restarts CDBar; `BattleCrySuccess` 87+ adjusts Savage Mauling bar using time-left; `EarthshatteringSpear` 107+ and `PierceArmor` 124+ warn/restart; `SavageMauling` 130+ stops a bar and aura removal 137+ warns/restarts. **Retail-era reference only**, not evidence of Forever-compatible module or spell IDs.

## Conditional load and portability boundary

`LittleWigs/LittleWigs.toc` requires BigWigs >=427 and load-on-demand; modern Midnight source lines use `[AllowLoadGameType standard]`. `LittleWigs_BurningCrusade/LittleWigs_BurningCrusade.toc` declares `AllowLoadGameType: tbc, wrath, cata, mists, standard`, load-on-demand and `X-BigWigs-LoadOn-InstanceId` lists that differ between Classic and standard, with direct module Lua paths. None of the supplied LittleWigs manifests declares Forever interface 16001. **UN:** whether Forever resolves game type to one of these manifest selectors and whether modules are loaded; presence in archive does not establish actual load. Contrast BigWigs 427.8 explicit Forever flag and 16001 manifest support. Do not conflate DBM `IsRestricted()` with Retail-only event registration.
